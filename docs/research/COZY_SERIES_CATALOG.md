## 调研范围与结论

本目录只收录作者 shubibubi 自己发布的 itch.io 页面，不使用转载站、资源聚合站或第三方再打包文件。作者当前公开页列出的同风格素材共 8 套：`Cozy Farm`、`Cozy Town`、`Cozy People`、`Cozy Interior`、`Cozy Fishing`、`100 Nature Things`、`100 Winter Things` 和 `100 summer things`。[作者官方主页](https://shubibubi.itch.io/)

其中前 7 套属于作者的 [“all things cozy” 官方组合](https://itch.io/s/157466/all-things-cozy-bundle)；`100 summer things` 是后续单独发布、仍在开发中的新包。作者没有单独发布名为 `Cozy UI` 的素材包；完整 UI 主要包含在 `Cozy Farm` 付费完整版中，免费版未声明包含这些 UI。

Project X 当前执行“免费、个人非商业、后期自制替换”政策，因此可以下载并本地保存这 8 套的免费版本，但必须遵守共同限制：

- 免费版仅允许用于非商业项目，可以修改。
- 免费版不能用于商业项目，也不能转售或再分发，即使已经修改。
- 作者表示署名为 appreciated（欢迎署名），不是页面写明的免费版强制条件；项目仍应主动记录作者和来源。
- 免费素材不能提交到公开仓库或随公开试玩包分发。若项目以后公开或商业化，免费版必须全部替换为自制素材；当前决定是不购买完整版。

## 落盘与授权记录规则

建议保持下载原包、项目候选和 Godot 运行资产分离：

```text
D:/Archer/Project X External Assets/
└─ shubibubi/
   ├─ cozy-farm/free-original/
   ├─ cozy-town/free-original/
   ├─ cozy-people/free-original/
   ├─ cozy-interior/free-original/
   ├─ cozy-fishing/free-original/
   ├─ nature-things/free-original/
   ├─ winter-things/free-original/
   └─ summerthings/free-original/

Project X/assets/third_party/shubibubi/
└─ 只复制本阶段实际试用的少量 PNG 和许可证快照
```

- 原始压缩包与解压副本放在 D 盘外部素材目录，不放进项目仓库。
- 每个包保存官方页面 URL、下载日期、免费版许可文本快照和原始文件名。
- 只有通过尺寸、透明通道、调色板和切片检查的少量 PNG 才进入 `assets/third_party/shubibubi/<pack>/`。
- 地图格、农田状态、碰撞和存档继续依赖 Project X 稳定 ID，不能依赖 Shubibubi 图集坐标。
- 免费版即使修改后仍禁止再分发，因此项目未来公开前必须执行第三方免费素材清退检查。

当前 HomeRegion 不应一次混入 8 套素材。第一张免费素材视觉样板只使用：

- Cozy Farm：草地/泥地、树、住宅、鸡、番茄、土豆。

Cozy People 免费角色缺少四方向，Cozy Fishing 免费版缺少海滩 TileSet；这两套现阶段只做动作结构和物品图标参考。Nature 与 Winter 在当前春季家园阶段只归档。
