# 输入与移动模块

## 核心价值

这是一套面向生活模拟的基础操作契约：游戏逻辑只读取具名动作，而不读取具体键位。它让 PC 原型可以立即使用 WASD，同时为后续手柄、触屏、按键重绑和本地化提示保留稳定接口。

## 当前动作

| 动作 | 默认键 | 行为类型 |
|---|---|---|
| `move_left` | A | 持续 |
| `move_right` | D | 持续 |
| `move_up` | W | 持续 |
| `move_down` | S | 持续 |
| `interact` | E | 单次 |

`PlayerController` 只使用上述动作。移动在物理帧中执行，互动在 UI 未消费输入时触发；对角输入被归一化，朝向则收敛为上下左右四个方向。

## 当前范围

灰盒场景提供边界限制、四方向自由移动、朝向显示和互动反馈。它刻意不包含地图碰撞、动画、工具、背包、NPC 或具体交互目标；这些会在网格交互与区域模块接入。

## 验收与删除条件

- 启动后可用 WASD 在矩形家园范围内自由移动，斜向移动不更快；
- 按 E 后状态栏显示当前朝向的互动反馈；
- 移动与互动完全通过 InputMap 动作读取；
- 若后续改为网格步进移动或触屏控制，保留动作名与 `PlayerController` 的公共职责，替换灰盒表现即可。
