# 时间、暂停与体力显示模块

## 核心价值

普通时间线不再只是可测试的数据：它已驱动当前场景的季节日期、时钟、天气预报和体力 HUD。原型以 1 秒现实时间推进 1 个游戏分钟，便于快速验证一天的生活节奏；该速率是场景可调参数，不是写死规则。

## 当前行为

- 新游戏从春季第 1 日 06:00 和满体力开始；
- 日历按每季 28 日计算；首个可玩版本只制作春季前 14 日内容，但时间模型不会在第 14 日失效；
- 当前天气和次日预报显示在 HUD 中，基础天气为由世界种子与日期稳定推导的晴、阴、雨；同一存档读取后不会跳变；
- 室外按 1 秒 = 1 游戏分钟推进；
- P 键暂停时钟与玩家输入，再按一次恢复；
- 住宅室内区域已调用 `set_indoor(true)`，室内按室外的 50% 流速推进；返回室外立即恢复正常流速；
- 与“祖父的旧床铺”互动会直接进入次日 06:00 并恢复体力，用于原型的连续跨日验证；
- 体力目前只展示 Game Session 状态；种植、采集、钓鱼和料理将在各自行动模块中消耗或恢复它。

## 边界

`GameClockController` 只把现实帧时间转为 Game Session 命令并广播 HUD 数据。季节、天气和睡眠的纯规则属于 `GameSession` 与 `GameRules`；世界场景只把床铺互动转换为睡眠命令。未来事件天气可以覆盖当天结果，但不能把随机数或场景节点写进存档，避免读档后的天气漂移。

## 验收与删除条件

- 启动后可见春季日数、06:00 起始时钟和体力；
- 等待一秒，时钟推进约一分钟；
- 与床铺互动后，日期前进一天、时间恢复至 06:00、体力回满，HUD 中的预报成为当天实际天气；
- 读取旧版会话快照后，仍能根据其日期和默认种子恢复稳定天气；
- P 暂停后时钟和移动均停止，恢复后继续；
- 后续若节奏测试不合格，仅调整 `seconds_per_game_minute`，不改变 Game Session 的时间语义。
