# Project X 美术规范 v1

## 视觉目标

温暖、明亮、有生活气息的日式掌机时代像素画。开发期统一采用 `Super Retro World - Farming` 的视觉语言，后续新增内容按其像素密度、轮廓和配色扩展；准备公开发布时再逐步替换为原创正式素材。

## 固定技术规格

- 内部分辨率：`480×270`
- PC 默认窗口：`1440×810`
- 世界网格：`16×16`
- 主角画布：`32×32`，实际人物主体约 `16×20`
- 主角基础行走：四方向，每方向 6 帧；当前表现适配层可镜像侧向帧
- 过滤：Nearest
- 缩放：整数倍优先
- 视角：俯视偏正面，建筑正面信息清晰
- 光源：左上方

## 素材职责

- TileSet：草地、道路、水、耕地、围栏和可重复环境细节。
- Sprite：人物、动物、树木、独特建筑、家具、道具和特效。
- 正式地图必须由可编辑瓦片层与独立精灵组成，不能依赖一张完整背景截图。
- 角色脚底锚点和碰撞体必须稳定；动画允许身体摆动，不能让脚底漂移。
- 屋顶、树冠等前景遮挡物在玩家位于其后方时必须升到角色前方，并降低透明度；碰撞只覆盖真实墙体、树干或水面，不覆盖整张精灵图。

## 外部参考边界

- 可学习经典作品的帧数、动作节奏、锚点和视觉层级。
- 正式主角不得通过原角色换色得到；骨架、发型、服装、剪影和像素必须重画。
- `Super Retro World - Farming` 整套素材允许作为个人开发期视觉基础，必须集中在 `assets/private/`，不得上传仓库或作为独立文件再分发。
- 其他私人白名单继续只允许已确认的矿石镇动物及部分室内结构；不得与统一开发期画风无控制混搭。
- 每个正式素材都必须登记来源、用途、状态和替换计划。

## 模块最低美术完成度

一个模块只有在以下条件全部满足时才算完成：

1. 玩家能看到与功能一致的可用像素素材。
2. 不以大色块作为正式表现。
3. 碰撞与可见物体一致，没有隐形墙或隐形交互。
4. 素材比例、调色板和光照方向符合本文档。
5. 通过自动检查和一次实际画面审查。
