# 矿石镇春季牧场本地地图模块

## 素材与边界

用户提供1024×704的《牧场物语：矿石镇的伙伴们》春季牧场PNG，用于个人本地游玩版本。原图SHA-256为`73F98BC9F001864D3D1D3B2B9481FDB6AF7795D3DBB82C4C87CC695DC0881301`。

- 项目外原图备份：`D:\Archer\Project X Private Sources\mineral_town_spring_farm\spring_farm_original.png`
- 项目内本地副本：`assets/private/mineral_town_spring_farm/spring_farm.png`
- `assets/private/`已由`.gitignore`排除，不进入未来公开仓库或公开素材包。
- 地图保持原始像素和1024×704尺寸，没有压缩、缩放、裁剪或重采样。

## 世界接入

- 地图作为`SpringFarmBackdrop`从世界坐标`(0,44)`开始显示，顶部44像素继续留给HUD。
- 玩家拥有`Camera2D`；室外边界覆盖整张地图，室内边界固定为480×270。
- 新游戏与离开住宅时落在主住宅门外；住宅门、鸡舍和田地使用春季地图专用格子映射。
- 私有地图存在时，只有地图中有明确可见对应物的住宅门、鸡舍和田地会注册为可互动对象；旧料理柜台、信箱、采集点和钓点会被完全停用，不能按 E 触发。
- 地图已承担建筑和水域的实体碰撞，所有旧网格物件在地图模式下均关闭自身碰撞，避免出现额外的隐形墙。
- 未翻土农田不额外绘制黑色方块；翻土和作物成长使用独立的本地作物图集覆盖显示。

## 碰撞

首版为主住宅、仓房/筒仓、鸡舍、左下建筑、池塘、树干、左侧水域和底部桥外水域配置粗矩形碰撞。桥口保持可通行。

这些碰撞用于阻止明显穿墙和下水，不代表最终逐像素地图碰撞。以后若获得原始TileSet，应改为TileMapLayer的地块碰撞；在此之前不为每棵草和装饰制作碎片碰撞。

## 回退策略

代码不直接预加载私有地图。如果文件缺失、无法作为Texture2D加载或尺寸不是1024×704，系统会关闭大地图、使用原480×270灰盒范围、原交互格子和原CC0设施外观；场景不会因私有文件缺失而解析失败。

## 验收

1. 新游戏显示春季牧场原图和矿石镇主角，人物没有蓝底。
2. 玩家可以在大地图上移动，相机跟随且不会越过地图外缘。
3. 住宅、仓房、鸡舍和池塘不可直接穿过，桥口可通行。
4. 住宅门口出现黄色E框，进入室内后画面恢复固定范围；出门回到原住宅门外。
5. 住宅门、田地和鸡舍只在其地图中的可见位置触发；旧料理台、信箱、采集点、钓点附近不会出现 E 框，按 E 也不会发生任何事。
6. 临时移走私有地图后，项目仍能以灰盒布局启动。
