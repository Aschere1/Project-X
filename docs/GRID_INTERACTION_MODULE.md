# 网格交互模块

## 核心价值

玩家可以保留生活模拟所需的自由移动，同时以面前的 16×16 格作为精确交互目标。这样不会把整个游戏锁死为格子步进，也不会让后续作物、门、工作台、柜台或居民各自实现一套距离判断。

## 交互契约

`GridInteractable` 是可复用的场景根节点，包含：

- 稳定的 `interaction_id`；
- 可本地化的显示名称与结果文本；
- 所在 `grid_cell`；
- 所属 `area_id`；
- `interacted` 信号。

默认对象根节点是 `StaticBody2D`，带 12×12 的静态碰撞体，因此料理柜台、信箱及以后放置在地面的设施会阻挡角色穿过。对象可通过 `blocks_movement` 声明是否阻挡：农田显式关闭碰撞，保证玩家能走进田地进行翻土、播种和收获。

世界场景通过 `project_x.grid_interactable` 分组注册对象，而不是按固定节点路径查找。注册键是“区域 + 网格”，不同区域可以安全复用同一格坐标。玩家进入当前区域的对象约一格半范围后，最近对象显示黄色选中框和 `E` 提示；玩家发出互动意图后，世界才将结果分发给该目标对象。

## 当前灰盒对象

- 旧料理柜台；
- 祖父的旧信箱；
- 空农田。
- 住宅入口、出口和床铺。

它们仅验证交互链路，不会修改背包、时间、体力或存档。后续料理、邮件和种植模块将替换各自的互动结果实现，但继续使用同一格子和信号边界。

## 验收与删除条件

- 靠近彩色方块时，出现黄色选中框和 `E` 提示；按 E 后状态栏显示对象对应文本；
- 附近没有对象时没有选中提示，按 E 不改变状态栏或游戏状态；
- 同一格不允许注册两个对象；
- 设施不能被角色穿过；农田仍可行走且可被选中互动；
- 若未来使用碰撞范围、鼠标或触屏交互，只替换世界的目标解析逻辑；`GridInteractable` 的对象契约保持不变。
