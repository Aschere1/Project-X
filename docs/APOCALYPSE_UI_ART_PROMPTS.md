# 末日生存 UI 美术提示词

## 使用原则

UI 美术只生成“无文字、无数字、无按钮文案”的组件。文字、图标组合、数值、快捷键提示和布局全部由 Godot 负责。所有组件应保持同一套末日乡土生存风格：深灰绿、旧铁锈红、脏米白、暗木色，边缘有轻微磨损，但信息层级必须清楚，不能把地图遮住。

通用格式：PNG、透明背景、无黑底、无棋盘格、无文字、无水印、无 logo、硬边像素风或低分辨率手绘像素风；组件单独居中，四周留透明边距，不要把多个 UI 组件拼在一张图里。

## 1. 家园轻量状态栏

```text
Create a small modular UI texture for a 2D Chinese zombie-apocalypse survival game. Design a narrow worn metal and dark wood status-bar frame for the top edge of the screen, with subtle chipped paint, rust, stitched canvas and muted gray-green colors. The frame must be simple, readable and low contrast so it does not cover the farm map. No text, no numbers, no icons, no buttons, no logo, no watermark. Transparent background, isolated UI component, pixel-art survival game style, clean horizontal shape, suitable for Godot nine-patch or StyleBox recreation.
```

## 推荐生成顺序

1. 圆形角色头像框和地图角色标记。
2. 互动提示框和家园功能区标签底板。
3. 县域地图地点标记套件和选中光圈。
4. 搜刮容器、稀有度边框、背包格子。
5. 状态图标、对话框、关系 UI。

所有生成结果先以透明 PNG 接入 Godot；如果生成结果带黑底或把文字画进图片，不直接使用，重新生成或交给图像工具清理。
