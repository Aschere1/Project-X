# 测试约定

## 当前测试边界

`GameSession` 是当前已确认的领域测试边界。测试仅通过其公开行为验证：

- 开始新游戏；
- 推进普通时间线；
- 消耗体力；
- 睡眠；
- 生成和恢复纯数据快照。

测试不会读取私有字段、依赖场景节点，或模拟 Godot 内部实现。`TimelineSaveRepository` 是存档的第二个测试边界：测试通过写入与读取公开槽位验证 JSON 快照和备份回退。

## 运行方式

在项目根目录运行：

```powershell
& '.\scripts\test_project.ps1'
```

该脚本会等待 Godot 进程结束，再读取本轮写入的测试标记。其 `APPDATA`、`LOCALAPPDATA`、`TEMP` 和 `TMP` 均限定到 `D:\Archer\Tools\Godot\4.7.1\project_x_profile`，不会向 C 盘写入项目运行数据。

## 当前覆盖

- 新游戏从第 1 日 06:00、满体力开始；
- 时间跨日时保留正确的时分余量；
- 体力不会低于 0；
- 睡眠开启下一天，并恢复起始时刻与满体力；
- 快照往返保留日期、时刻和体力。
- 存档仓储可以保存并恢复普通时间线快照；
- 主存档损坏时，仓储回退到最后一个有效备份。
- 背包处理同类物品堆叠、容量不足和快照恢复；
- 农田只接受首次锄头行动，并可恢复已翻土状态。
