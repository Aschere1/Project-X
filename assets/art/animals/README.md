# 家园动物视觉

`starter_hen.png` 和 `super_retro_hen_sheet.png` 是为当前开发版补齐缺失母鸡视觉的原创候选素材。`super_retro_hen_idle.png` 保留为生成初版记录，正式场景使用已经补眼的 `starter_hen.png`。

- 规格：16×20 像素单帧；图集为 3×2，共六帧。
- 顺序：正面待机、背面待机、右侧待机、左侧行走、右侧行走、备用侧面姿态。
- 处理：按统一提示生成后，去除色键背景、最近邻裁切到项目网格；禁止使用同包鸟类素材冒充鸡。
- 当前正式场景引用带明确眼睛像素的 `starter_hen.png`。图集在人工逐像素清理和动画验收前不作为最终动画源。
