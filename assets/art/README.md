# Original Runtime Art

这里存放 Project X 的原创正式运行素材。当前首批素材由 `scripts/generate_original_pixel_assets.ps1` 以确定性像素绘制规则生成，便于重复生成、审查和继续人工精修。

- `tilesets/home_terrain.png`：16×16 家园地形图集
- `characters/player_walk.png`：24×32，三方向各四帧的原创主角基础行走
- `buildings/farmhouse.png`：原创农舍外观
- `buildings/chicken_coop.png`：原创鸡舍外观
- `props/tree.png`：原创春季树木
- `props/home_props.png`：原创小型家园道具

这些文件不是矿石镇素材的换色版本，也不依赖 `assets/private/` 才能运行。
