## 当前产品决定

- 末日家园是静态地图热点，不显示常驻头像。
- 末日流程没有 WASD、碰撞箱、靠近功能区或 E 键互动。
- 主角只在背包/装备、剧情对话等必要 UI 中以立绘形式出现；当前尚未接入正式立绘。
- 家园热点默认透明，悬停只使用低饱和灰绿色弱提示。
- 背包使用常规生存游戏单格库存，不是俄罗斯方块体积库存。
- 普通用品单格最多叠加 16；武器不叠加。
- 家园仓储按格数计算，不计算负重；背包保留负重显示。
- 搜索只揭示物资，玩家随后逐件领取或全部领取，不会自动塞入背包。
- UI 基准为 480×256 内容、8–10 px 紧凑字号；不要重新放大菜单、Tooltip 或按钮。
- B = Backpack，Esc/P = 菜单，S = Save；末日流程没有移动按键。

## 旧牧场内容如何处理

旧牧场源码、资源、测试与历史文档仍在项目里。它们不是当前主线，不要优先阅读，也不要删除。只有在明确复用时间、天气、种植、料理或其他领域逻辑时，才进入对应旧模块；不要把旧 `HomeRegion`、行走头像或碰撞式功能区重新接回末日家园。
